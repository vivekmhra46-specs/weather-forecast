                                    🌊 Weather Report System 

A modern desktop-based  Weather Report System** built using Python Tkinter for the graphical interface and C Programming for weather report processing. The project features an elegant Ocean Blue Theme, weather analytics, report generation, and file-saving capabilities.


✨ Features

🌤 Weather Report Generation

* Generate detailed weather reports instantly.
* Input:

  * City Name
  * Temperature
  * Humidity
  * Wind Speed
  * Weather Condition

🌡 Temperature Unit Conversion

* Supports:

  * Celsius (°C)
  * Fahrenheit (°F)
 🎨 Ocean Blue UI

* Modern and professional design.
* Smooth blue color palette.
* User-friendly interface.

### 🌙 Theme Toggle

* Dark Mode
* Light Mode

### 📋 Report Output Panel

* Color-highlighted report sections.
* Alerts and warnings displayed separately.
* Forecast data formatting.

### 💾 Save Reports

* Save generated reports as a text file.
* Easy access for future reference.

### 🗑 Clear Function

* Reset all fields with one click.

## 🛠 Technologies Used

| Technology        | Purpose                   |
| ----------------- | ------------------------- |
| Python            | GUI Development           |
| Tkinter           | Desktop Interface         |
| C Language        | Weather Processing Engine |
| Subprocess Module | Python ↔ C Communication  |

## ⚙ How It Works

1. User enters weather details.
2. Python GUI collects the information.
3. Data is passed to the C backend using subprocess communication.
4. C program processes the data.
5. Generated report is displayed in the GUI.
6. Report can be saved locally.

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/weather-report-system.git
cd weather-report-system
```

### Compile C Program

```bash
gcc newgui.c -o weather.exe
```

### Run Application

```bash
python weather.py
```
